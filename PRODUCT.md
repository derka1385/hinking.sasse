# Hiking Club

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
SSE students applying to the Hiking Club committee, and committee members reviewing applications and arranging interviews.

## Product Purpose
Extend the existing Hiking Club website with a dedicated application form and a private recruitment workspace.

## Capabilities and Constraints
- Collect first name, last name, email, programme/year, previous experience, Hiking/Mountaineering interests and selected committee roles.
- Preserve the eight English role names and descriptions supplied by the user.
- Notify a configurable committee inbox after each application. The user has no SMTP service yet and requested configuration in the private workspace.
- Review applicants by role and prepare interview schedules by candidate and role, with a calendar export.
- Keep existing website and mountain/entrance behaviour. Preview locally; no Git push or publication is authorised.
- Build directly in code using the existing identity, as selected by the user on 27 October 2026.

## Brand Commitments
Preserve the existing Hiking Club identity and official logo assets. The user-supplied Figma identity is the brand reference already recorded in the project.

## Evidence on Hand
Existing website, local official vector logos, self-hosted fonts and the eight role descriptions in the current request. No recruitment deadline or selection criteria have been supplied.
